# Ezba-Posta
**Building secure communication systems from scratch.**

Ezba-Posta is an educational cryptography project focused on understanding, implementing, and experimenting with cryptographic algorithms using Python.

The project is part of the **Ezba Development Journey**, exploring cryptography and secure communication systems from the ground up.

## Project Roadmap

- [x] **DES:** Implement DES encryption and decryption from scratch.
- [ ] **Ezba Post v1:** Build a simple messaging application using DES.
- [ ] **Abu Wahdan:** Experiment with cryptanalysis and educational attack scenarios.
- [ ] **AES-128:** Implement AES encryption and decryption from scratch.
- [ ] **Ezba Post 2.0:** Upgrade the messaging application with AES and message authentication.
- [ ] **Ezba Security Lab:** Explore cryptographic attacks, vulnerabilities, and security concepts.

## Implementations

| Algorithm | Status | Language |

| DES | Completed | Python |

## Project Goals

- Understand how cryptographic algorithms work internally.
- Implement encryption algorithms without relying on cryptography libraries.
- Validate implementations using official test vectors.
- Explore cryptanalysis through practical experiments.
- Apply cryptographic concepts in real-world-inspired projects.

## Disclaimer

This project is intended for educational purposes only.
